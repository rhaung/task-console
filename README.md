# Task Console

A small day/week to-do application with browser-based task storage, button-driven controls, and a time-aware animated background.

## Run locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

After pushing the repository to GitHub, open **Settings → Pages**, choose **Deploy from a branch**, then select the `main` branch and the `/(root)` folder. GitHub will provide the public site address.

## Background assets

`background.html` swaps among the included WebM videos based on the visitor's local time. The video files are stored in this repository so the background works both locally and when hosted.
